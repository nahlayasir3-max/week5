##  Required CSS Concepts Checklist
| Lesson | Concept | Where I Used It (Exact Place) |
|:------:|:--------|:------------------------------|
| #39 | `border-radius` | `header`, `.parent div`, `img`, `button` using `var(--main-border-redius)` |
| #40 | `box-shadow` | `.parent div:hover { box-shadow: 10px 10px 30px 2px ...; }` |
| #41 | `box-sizing: border-box` | `* { box-sizing: border-box; }` (Global reset at top of CSS) |
| #42 | `transition` | `.parent div { transition: all .3s linear; }` |
| #43 | `!important` | `body { background-color: ... !important }` (Used once to override inline style, with comment) |
| #44 | Margin Collapse | Vertical margins between `p` & `button` would collapse.  |
| #45 | CSS Variables | `:root { --main-color, --main-border-redius, --main-padding, --main-margin, --card-bg }` |
| #46–49 | Flexbox – Parent | `.parent { display: flex; flex-wrap: wrap; justify-content: center; align-items: center; gap: 50px; }` |
| #50–53 | Flexbox – Child | `.card1 { order: 3; }` |
